# Политика конфиденциальности приложения «ГириБро»

Дата последнего обновления: 21 ноября 2026 г.

## 1. Общие сведения

Настоящая Политика описывает, как приложение «ГириБро» (далее — Приложение)
обращается с данными пользователя. Разработчик Приложения:
Константинов Станислав Александрович (далее — Разработчик).

Приложение предназначено для ведения дневника гиревых тренировок, учёта веса и
замеров тела, просмотра нормативов, календаря соревнований и создания
фото-карточек тренировок.

## 2. Какие данные используются

2.1. Приложение не собирает, не передаёт и не продаёт персональные данные
Разработчику или третьим лицам. У Приложения нет доступа к интернету, нет
аккаунтов, облачной синхронизации, рекламы, аналитики и трекеров.

2.2. Пользователь может самостоятельно внести в Приложение:

- тренировки, подходы, упражнения, заметки;
- вес тела и замеры (талия, грудь, бёдра, плечо, бедро);
- профиль спортсмена (пол, возрастная группа, вес для нормативов);
- настройки Приложения.

Эти данные хранятся только в локальной базе на устройстве пользователя. Они не
отправляются на серверы Разработчика и не становятся доступны ему.

2.3. Приложение не запрашивает доступ к контактам, геолокации, микрофону,
галерее и ко всему внешнему хранилищу. Доступ к камере запрашивается только
при добровольном включении счётчика повторов. Для таймера используются
уведомления, foreground-сервис и вибрация. Для автоматических резервных копий
Приложение получает доступ только к той папке, которую пользователь явно
выбрал через системный диалог Android.

## 3. Фото-карточки, экспорт и резервные копии

3.1. Фото-карточки тренировок формируются локально на устройстве.

3.2. Если пользователь нажимает «Поделиться», файл передаётся в выбранное им
приложение или сервис через системное меню Android. Дальнейшая обработка файла
регулируется правилами и политикой получателя. Разработчик не получает копию
файла, за исключением архива технических логов, который пользователь отправил
сам по пункту 3.9.

3.3. Резервная копия создаётся по действию пользователя или автоматически, если
он включил автобэкап. Копия сохраняется в выбранное пользователем место через
системный файловый диалог; Разработчик не имеет доступа к этой копии. По желанию
пользователь может защитить копию паролем: файл шифруется на устройстве
(AES-GCM), а пароль для автоматических копий хранится в зашифрованном виде в
Android Keystore и не передаётся Разработчику.

3.4. Для напоминания о резервной копии Приложение может показывать локальное
уведомление. Разрешение на уведомления необязательно: без него автобэкап
продолжает работать, но напоминание не появляется.

3.5. Счётчик повторов использует фронтальную камеру. Кадры обрабатываются
на устройстве встроенной моделью распознавания позы: в памяти остаются только
координаты скелета на время подхода, после выхода с экрана счётчика они
отбрасываются.

3.6. Для подхода с режимом «Запись» Приложение может сохранить видео в папку,
которую пользователь выбирает через системный диалог Android (SAF). Доступ к
папке остаётся на устройстве; Приложение сохраняет только выбранный адрес папки
в локальных настройках и не имеет доступа к другим файлам. Видео не
передаётся Разработчику и третьим лицам. В режиме «Счёт» и при ручном открытии
счётчика видео не записывается. Пользователь может в любой момент отказать
Приложению в доступе к папке через настройки Android.

3.7. Разрешение на камеру необязательно: без него остальные функции Приложения
работают как обычно. Библиотека распознавания содержит встроенный компонент
статистики, но он не может отправить данные: у Приложения нет разрешения на
доступ в интернет, и все такие попытки блокируются системой на устройстве.

3.8. Для разбора сбоев Приложение ведёт локальный технический журнал во
внутренней памяти устройства. В него попадают версия Приложения, модель
устройства, краткие сообщения о неполадках и стек-трейсы ошибок. В журнал не
пишутся тренировки, заметки, вес и замеры тела, профиль спортсмена, пароли,
координаты скелета и кадры с камеры.

3.9. В разделе «Настройки → Связь с автором» пользователь может нажать
«Отправить логи». Приложение подготовит архив с техническим журналом и
откроет системный почтовый клиент с письмом на адрес
**fess66690@yandex.ru**. Само Приложение письмо не отправляет: отправку
подтверждает пользователь в выбранном им почтовом клиенте. Если письмо не
отправлено, Разработчик не получает журнал. Доступ в интернет для этого не
требуется, и разрешение `INTERNET` в Приложении отсутствует.

## 4. Хранение и удаление данных

4.1. Данные хранятся на устройстве до тех пор, пока пользователь их не удалит.

4.2. Удалить тренировки и замеры можно в настройках Приложения. Полностью
удалить данные можно также через настройки Android («Очистить данные») или
удалив Приложение.

4.3. Резервные копии, созданные пользователем, хранятся в выбранном им месте.
Их удаление выполняется средствами файлового менеджера или соответствующего
сервиса.

4.4. Технический журнал хранится в служебной папке кэша Приложения и
автоматически очищается системой Android вместе с кэшем. Удалить его можно
также через настройки Android («Очистить кэш») или удалив Приложение.

## 5. Передача данных третьим лицам

Разработчик не передаёт данные пользователя третьим лицам. Передача файла
возможна только по явному действию пользователя через системное меню
«Поделиться», при сохранении резервной копии в выбранное им место или когда
он сам отправляет письмо с техническими логами через почтовый клиент.

Приложение не имеет разрешения `INTERNET` и не отправляет данные по сети
самостоятельно. Все действия по передаче файлов и писем выполняются другими
приложениями, выбранными пользователем через системные диалоги Android.
